使用帮助

Mermaid Markdown Editor 功能速查 & 快捷键

1. 双模式编辑

  • Mermaid 模式：左侧写 Mermaid 源码，右侧实时渲染流程图，可直接在预览上拖拽节点、右键新增/删除/复制。
  • Markdown 模式：左侧写 Markdown，右侧预览（支持代码高亮与内嵌 Mermaid 代码块）。
  • 顶栏切换 Tab；"自动更新"关闭后编辑不触发实时渲染，可用 Ctrl+S 手动刷新。

2. 画布操作

  • 缩放：工具栏 +/- / 1:1 按钮，或 Ctrl + 滚轮。
  • 平移：按住空白处拖动，或按住中键拖动。
  • 网格：切换背景网格辅助对齐。
  • 拖拽布局：开启后可自由拖动节点/子图到任意位置，位置在源码自动更新后仍保持（免重渲染）。
  • 自动布局：清除所有手动位置，由 Mermaid 重新自动排布。
  • 撤销布局：恢复至最近一次自动布局之前的手动布局。

3. 图形编辑（右键菜单）

  • 空白处右键：新增节点 / 连线 / 子图；粘贴。
  • 节点右键：编辑文本 / 改形状 / 设置 emoji / 复制 / 删除。
  • 连线右键：编辑文字 / 切换箭头类型 / 删除。
  • 子图右键：编辑标题 / 粘贴子图 / 删除子图（保留/移除内部节点可选）。

4. 导出

  • SVG / PNG：导出当前画布的矢量/位图。
  • DOCX：导出 Markdown 为 Word 文档（含图片）。
  • Visio（.vsdx）：需要本机安装 Microsoft Visio（通过 COM 自动化转换 SVG）。

6. 提示

  • 默认不打开 DevTools；开发调试请用 set MME_DEVTOOLS=1 && npm start。
  • Mermaid 渲染对齐 VSCode 插件 bierner.markdown-mermaid（Mermaid 11.14）。
  • 单张图如需切换 ELK 布局，在源码头部加：%%{init: {"layout": "elk"}}%%。
